FLAG 1 (open) — CORS missing on the new main.py
----------------------------------------------------------------
WHAT: The matching wrapper (main.py) has no CORS middleware.

WHY IT MATTERS: Browsers block JavaScript on one origin from reading
another origin's responses. When the React dashboard (e.g. localhost:5173)
tries to call http://127.0.0.1:8000/match, the browser will block it and
the dashboard will silently fail with a CORS error in the console.
Python test scripts are NOT affected — only browsers are. That is why
all backend tests pass today.

FIX (when frontend work starts, ~6 lines, same block already used in
main2.py):

    from fastapi.middleware.cors import CORSMiddleware

    app.add_middleware(
        CORSMiddleware,
        allow_origins=["*"],
        allow_methods=["*"],
        allow_headers=["*"],
    )

(For the demo, keep "*" — restrict origins only if asked in judging Q&A
about security.)
